# 0024 — Publish dialog explains names & passphrases

**Date:** 2026-09-17
**Triggered by:** Owner — "The dialog needs to provide more info on what
trips are and how to use them. Outside of 4chan they aren't well known."

## What changed

`name#passphrase` is insider syntax; the publish dialog now carries a
collapsed explainer (details/summary, `.trip-help`) in plain words,
optional-first (owner round 2):

- ALL of it is optional — empty is the default and completely fine;
- USE a passphrase when: you'll maintain the track, want to be the only
  one who can save over it, or want recognizable ownership;
- SKIP it when: quick sketch, happy for anyone to improve it in place,
  or you don't want to manage a phrase — and signing never locks a
  track away (copies stay open);
- mechanics: bare name = byline label anyone could type; `#phrase`
  signs it (`Alex!9f3ab2c1`), same phrase = same you on any device;
  browser remembers it, no account, no reset — a lost phrase leaves the
  track as it is.

Placeholder leads with "Optional". No behavior changes; e2e pins the
summary ("Optional"), the when/when-not pair, and the no-reset line.
